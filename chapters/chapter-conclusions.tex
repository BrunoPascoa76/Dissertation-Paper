\chapter{Conclusões e Trabalho Futuro}
\label{chap:conclusions}

\begin{introduction}
Este capítulo descreve as conclusões gerais retiradas ao longo do trabalho, bem como sugestões de trabalho futuro.
\end{introduction}


\section{Conclusões}

Este trabalho teve como objetivo demonstrar a viabilidade de uma abordagem baseada em \textit{streaming} para monitorização contínua durante o uso normal do computador utilizando apenas periféricos de uso comum - interfaces do próprio computador e \textit{wearables off-the-shelf}.
Para este propósito, foi estabelecido um cenário concreto de monitorização remota individual, no âmbito da qual se considera terem sido atingidos os seguintes resultados:
\begin{itemize}
    \item Implementação de um sistema baseado em \textit{streaming} capaz de recolher dados de câmara, teclado e \textit{smartwatch}.
    \item Visualização das métricas recolhidas em tempo real através de um \textit{dashboard}.
    \item Implementação de uma arquitetura extensível a outros cenários de monitorização contínua, suportando a monitorização de vários utilizadores em simultâneo e facilitando a adição de suporte a novas fontes de dados.
    \item Verificação funcional do sistema através da simulação de uma situação típica (distração com o telemóvel durante a sessão de tutoria).
\end{itemize}

Em geral, considera-se que a prova de conceito desenvolvida permite servir como exemplo da viabilidade de abordagens baseadas em \textit{streaming} em cenários de monitorização contínua, cumprindo-se assim o objetivo estabelecido para este trabalho.

Este trabalho apresentou o desenvolvimento de uma \textit{pipeline} de processamento em \textit{streaming} de dados de sensores, abordando os desafios de resiliência e integridade, bem como o equilíbrio entre robustez e modularidade.
Em geral, considera-se que os objetivos propostos foram cumpridos na sua totalidade: foi desenvolvido um sistema baseado em \textit{streaming} capaz de ser estendido para suportar novas fontes de dados com base no caso de uso, foi verificado o seu funcionamento através da recolha de dados de periféricos e \textit{wearables} e considera-se que esta prova de conceito permite servir como exemplo da viabilidade do \textit{streaming} para monitorização contínua durante o uso do computador.

\section{Trabalho Futuro}
Apesar dos avanços alcançados, existem ainda funcionalidades e aspetos do trabalho que merecem investigação adicional. Estas incluem: 
\begin{itemize}
    \item Determinar os limites de escalabilidade do sistema.
    \item Avaliar o impacto da distância física na latência e fiabilidade do sistema.
    \item Explorar ferramentas de processamento em \textit{streaming} para operações mais complexas como o Kafka Streams.
    \item Explorar o protocolo \ac{BLE} para extração de dados de dispositivos \textit{wearables} que não suportem comunicação via \ac{MQTT} (como \textit{smart rings}).
    \item Explorar a integração e treino de modelos de Inteligência Artificial no sistema, avaliando o seu impacto no sistema.
    \item Avaliar alternativas distribuídas para o \textit{broker} remoto e o seu impacto na escalabilidade horizontal do sistema.
\end{itemize}
