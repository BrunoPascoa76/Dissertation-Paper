    \begin{introduction}
    Este capítulo contextualiza e motiva o trabalho, ao apresentar o computador como fonte de dados para monitorização contínua do estado do utilizador, apresenta o foco principal e exemplos de casos de uso para a \textit{framework} proposta e define os objetivos esperados para este trabalho.
    \end{introduction}

    \section{Contexto e Motivação}

    O uso prolongado do computador em contexto profissional ou estudantil cria oportunidades únicas para a monitorização contínua do estado do utilizador, visto que permite não só o uso de sensores tradicionais (como sensores autónomos ou os sensores embutidos num dispositivo \textit{wearable}), mas também aproveitar os próprios periféricos de entrada do computador (como o rato, o teclado ou a \textit{webcam}).
    Estes dispositivos, embora não sejam tipicamente classificados como sensores, possibilitam a extração de dados biométricos e comportamentais capazes de refletir o estado do utilizador, permitindo, por exemplo, inferir o estado emocional com base na dinâmica de digitação no teclado~\cite{keyboard_speed_study,keyboard_correction_study}.

    De forma a aproveitar esta oportunidade, este trabalho foca-se principalmente na criação de uma \texit{framework} para monitorização simultânea do estado de vários utilizadores durante o uso normal do computador, utilizando periféricos presentes no próprio computador (como o teclado, o rato ou a \textit{webcam}), bem como sensores \textit{wearable off-the-shelf} de uso comum (como \textit{smartwatches}). 
    Com base nestas características, esta \textit{framework} pode ser útil em várias situações como, por exemplo, para medir o nível de \textit{stress} em situações de teletrabalho (utilizando a frequência cardíaca proveniente de um \textit{smartwatch} e a dinâmica de digitação no teclado) ou para medir o nível  de atenção de alunos em situação de \textit{e-learning} (recorrendo à direção do olhar e a frequência do pestanejar através de uma \textit{webcam}).

    Contudo, o valor deste trabalho não reside apenas na criação de uma framework de monitorização funcional, mas também na exploração do \textit{streaming} como estratégia para recolha de dados de forma contínua neste tipo de cenários, utilizando ferramentas de \textit{streaming} já estabelecidas sempre que possível e descrevendo possíveis vantagens e problemas encontrados.

    \section{Objetivos}\label{sec:objectives}
    
    Com base no cenário descrito acima, os objetivos específicos do trabalho são:
    \begin{itemize}
        \item Conceber e implementar uma \textit{framework} que recorre ao \textit{streaming} para a monitorização contínua de vários utilizadores durante o uso normal do computador.
        \item Integrar fontes de dados heterogénias, permitindo a recolha de dados de periféricos nativos do computador e de dispositivos \textit{wearable off-the-shelf}.
        \item Explorar o uso de ferramentas já estabelecidas para a criação da \textit{pipeline} de ingestão de dados, sempre que possível.
        \item Assegurar a extensibilidade da \textit{framework} para periféricos de computador e dispositivos \textit{wearable off-the-shelf}, minimizando e localizando tanto quanto possível o esforço de integração destas fontes de dados.
        \item Documentar as vantagens e dificuldades encontradas na implementação desta \textit{framework}.
        \item Validar o funcionamento do sistema através de um fluxo \textit{end-to-end} com dados reais e realizar uma análise analítica de escalabilidade.
    \end{itemize}
