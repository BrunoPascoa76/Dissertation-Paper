    \section{Contexto e Motivação}

    O uso prolongado do computador em contextos de trabalho e estudo cria oportunidades únicas para a monitorização contínua do estado do utilizador através dos sensores integrados ou conectáveis a este dispositivo~\cite{keyboard_correction_study,keyboard_speed_study,facial_hrv_study}. Estes sensores permitem recolher não só dados biométricos, como a frequência cardíaca ou expressões faciais~\cite{facial_hrv_study}, mas também dados comportamentais, como padrões de digitação no teclado~\cite{keyboard_speed_study,keyboard_correction_study}.

    Como se verá no Capítulo~\ref{chap:estadodaarte}, as plataformas \textit{open-source} existentes para recolha de dados de sensores (como o RADAR-base~\cite{radarbase} ou a AWARE Framework~\cite{aware}, por exemplo) focam-se maioritariamente em dispositivos móveis e não suportam sensores de computador, não existindo atualmente nenhuma solução adequada à recolha contínua e remota de dados em estudos longitudinais neste contexto. 
    Este trabalho propõe, por isso, uma infraestrutura em \textit{streaming} que permite a monitorização contínua e assíncrona de dados de sensores de forma modular, extensível e agnóstica ao tipo de sensor.

    \section{Objetivos}\label{sec:objectives}

    Os objetivos concretos do trabalho são:
    \begin{itemize}
        \item Desenvolver um servidor de ingestão de dados baseado em \textit{streaming}, capaz de receber dados de múltiplos sensores e de múltiplos utilizadores em simultâneo.
        \item Definir um protocolo de ingestão agnóstico baseado num contrato mínimo que permita a adição de novos tipos de sensores sem alterar o servidor.
        \item Desenvolver uma aplicação de \textit{desktop} para demonstração das capacidades do sistema. Esta aplicação deverá ter uma estrutura modular que facilite a integração de novos sensores.
        \item Integrar um sensor externo \textit{off-the-shelf} através de um dispositivo \textit{wearable}.
        \item Validar o sistema através de um fluxo \textit{end-to-end} com dados reais e realizar uma análise analítica de escalabilidade.
    \end{itemize}
    
    \section{Metodologia}

    De modo a guiar a concretização dos objetivos acima descritos, decidi adotar uma abordagem estruturada baseada nas seguintes fases:
    \begin{enumerate}
        \item Análise do estado da arte para identificar sensores relevantes para identificação de lacunas e alternativas existentes, bem como sensores relevantes para a validação do sistema.
        \item Criação de uma arquitetura conceptual baseada em componentes lógicos.
        \item Identificação de limitações técnicas na comunicação entre componentes.
        \item Seleção das tecnologias mais apropriadas para a implementação de cada componente lógico.
        \item Implementação e validação incremental de cada componente lógico.
        \item Validação do fluxo \textit{end-to-end} utilizando dados reais.
        \item Análise analítica da escalabilidade do sistema.
    \end{enumerate}
