    \begin{introduction}
    Este capítulo contextualiza e motiva o trabalho, ao apresentar o computador como fonte de dados para monitorização contínua do estado do utilizador, apresenta o foco principal e exemplos de casos de uso para a \textit{framework} proposta e define os objetivos esperados para este trabalho.
    \end{introduction}

    \section{Contexto e Motivação}

    O uso prolongado do computador em contexto profissional ou estudantil cria oportunidades únicas para a monitorização contínua do estado do utilizador, visto que permite não só o uso de sensores tradicionais (como sensores autónomos ou os sensores embutidos num dispositivo \textit{wearable}), mas também aproveitar os próprios periféricos de entrada do computador (como o rato, o teclado ou a \textit{webcam}).
    Estes dispositivos, embora não sejam tipicamente classificados como sensores, possibilitam a extração de dados biométricos e comportamentais capazes de refletir o estado do utilizador, permitindo, por exemplo, inferir o estado emocional com base na dinâmica de digitação no teclado~\cite{keyboard_speed_study,keyboard_correction_study}.

    Este tipo de monitorização é particularmente útil em contextos não presenciais como o ensino remoto ou o teletrabalho, onde a distância física limita a perceção do estado do utilizador~\cite{online_classes_sharma}, bem como em situações presenciais onde a observação direta poderá não ser suficiente, como a deteção de stresse em empregados.
    Contudo, ao contrário dos estudos laboratoriais, onde os dados apenas interessam no final da recolha, num cenário real o objetivo é responder às mudanças do estado de cada indivíduo à medida que estas occorem. Por esta razão, a tomada de decisões exige a atualização dos dados em tempo real (ou com latência reduzida), sendo por isso necessário adotar uma abordagem em \textit{streaming}.

    \section{Objetivos}\label{sec:objectives}

    Com base no cenário acima descrito, este trabalho foca-se na criação de uma \textit{framework} baseada em \textit{streaming} para monitorização simultânea do estado de vários utilizadores durante o uso normal do computador, utilizando periféricos presentes no próprio computador ou dispositivos \textit{wearables off-the-shelf}, com o objetivo de demonstrar a exequibilidade de uma solução baseada em \textit{streaming} para monitorização contínua, bem como explorar alguns dos periféricos (e métricas deles extraídos) utilizados na literatura para estimar o estado do utilizador.

    Para concretizar esta meta global, definem-se os seguintes objetivos específicos:
    \begin{itemize}
        \item \textbf{Demonstrar a exequibilidade do paradigma de \textit{streaming}:} Comprovar a viabilidade técnica de uma arquitetura de processamento contínuo baseada em \textit{streaming} para a monitorização contínua de vários utilizadores durante o uso do computador, utilizando sensores heterogénios.
        \item \textbf{Integrar fontes de dados fundamentadas na literatura:} Integrar fontes de dados e métricas fundamentados em estudos científicos anteriores, evitando escolhas arbitrárias, para estimar o estado do utilizador no âmbito da prova de conceito.
        \item \textbf{Ilustrar a monitorização em tempo real:} Integrar um mecanismo de visualização e agregação de dados (recorrendo a ferramentas como o \textit{InfluxDB} e o \textit{Grafana}) para demonstrar o comportamento funcional do fluxo \textit{end-to-end} num cenário controlado.
        \item \textbf{Projetar uma arquitetura modular:} Desenvolver a solução técnica garantindo que a estrutura conceptual sirva de base sólida para futuras expansões de novos tipos de sensores ou fontes de dados.
    \end{itemize}
