\chapter{Estado da Arte}
\label{chap:estadodaarte}

\begin{introduction}
Este capítulo descreve o estado da arte atual relativamente à monitorização do estado emocional do utilizador, bem como arquiteturas e metodologias de processamento contínuo de dados, identificando o trabalho já realizado nestas áreas, bem como as lacunas identificadas.
\end{introduction}

\section{Sensores e Monitorização do Estado Emocional}

Diversos estudos procuram explorar possíveis correlações entre um ou mais sensores (câmara, rato, teclado, entre outros) e o estado emocional do participante. Dentro destes, os mais comuns são os que utilizam sensores presentes em dispositivos que o utilizador comum já possui (como computador ou telemóvel), devido à sua utilidade prática.
Estes estudos utilizam várias abordagens para estabelecer estas correlações, contudo tendem a ser limitados em termos de análise contínua e escalabilidade das suas soluções de processamento de dados.

Diversos estudos conseguiram estabelecer uma correlação entre o uso do teclado e o nível de atenção e frustração do utilizador. Em particular, apesar de ambos terem considerado útil a frequência do uso de backspace, Maalej e Kallel~\cite{keyboard_speed_study} focaram-se mais na duração de cada tecla e intervalos entre teclas, enquanto que Epp et al.~\cite{keyboard_correction_study} focaram-se mais no tipo de caracteres (incluindo o número de caracteres especiais).

Para além do teclado, existem também estudos que exploram dados de \ac{HRV} (obtido via smartwatch) e dados faciais para estimar o estado emocional do utilizador. Em particular, um estudo realizado por Quiroz et al.~\cite{facial_hrv_study} integra dados de landmarks faciais obtidos por webcam com valores de HRV obtidos via smartwatch enquanto os utilizadores assistiam a filmes ou ouviam música (com o objetivo de despoletar certas emoções). Os resultados obtidos demonstram a eficácia de combinar dados de vários sensores para prever o estado emocional do utilizador de forma mais precisa.

\section{Principal Lacuna Identificada nos Estudos}

Apesar de, como exemplificado acima, existirem diversos estudos que relacionam dados de sensores (ou até uma combinação de sensores) ao estado emocional do utilizador, uma lacuna presente em todos os estudos é a falta de estudos de longo prazo, focando-se principalmente na recolha de dados numa sessão em particular.

Esta lacuna aparenta surgir devido à falta de soluções que permitam a recolha de dados de sensores de vários utilizadores de forma remota e a longo prazo, contudo o meu objetivo com este trabalho não é criar uma arquitetura que me permita realizar um estudo a longo prazo, mas sim criar uma base tecnológica que facilite a execução destes estudos por outros investigadores.

\section{Plataformas de Recolha de Dados de Sensores}

Adicionalmente, para além de estudos científicos, existem também plataformas já estabelecidas que permitem a recolha e tratamento de dados de sensores, destacando-se em particular o RADAR-base~\cite{radarbase} e a AWARE~Framework~\cite{aware}.

\subsection{RADAR-base}

A RADAR-base~\cite{radarbase} é uma plataforma open source que permite a recolha de dados para estudos clínicos não só utilizando sensores do telemóvel a partir de uma app Android ou iOS, mas também sensores externos como wearables ou sensores \ac{IoT}, possuindo suporte oficial para diversos modelos de sensores.
Para além disso, esta plataforma oferece também a opção de acompanhar os dados com um questionário preenchido por cada utilizador.

\subsection{AWARE Framework}

De forma similar à RADAR-base, a AWARE Framework é uma plataforma de recolha de dados para estudos científicos que permite recolher dados dos sensores internos de um telemóvel Android ou iOS, bem como a realização de questionários. Contudo, apesar de ambos utilizarem um sistema baseado em plugins, a AWARE Framework não possui (até à data) capacidade de recolha de sensores externos ao telemóvel e suportando oficialmente um número menor de sensores do próprio telemóvel.

\section{Principais Lacunas Identifcadas nas Plataformas}

Apesar destas plataformas oferecerem soluções robustas, fáceis de utilizar e com funcionalidades complementares valiosas (como os questionários), estas soluções não são livremente extensíveis, não sendo possível o uso de sensores para além dos oficialmente suportados, sendo essa lacuna ainda mais evidente por nenhum destes proporcionar suporte parta o computador e respetivos dispositivos de input.
